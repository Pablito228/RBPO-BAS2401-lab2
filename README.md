# РБПО, лабораторная работа №2

REST API для аренды туристического снаряжения. Данные хранятся в памяти, поэтому после перезапуска приложения очищаются.

## Запуск

```bash
mvn spring-boot:run
```

Сервер запускается на `http://localhost:8080`.

## Ресурсы

- `/api/users`
- `/api/equipment-units`
- `/api/rental-orders`
- `/api/rental-items`
- `/api/inspection-records`

Для каждого ресурса реализованы `GET`, `GET /{id}`, `POST`, `PATCH /{id}`, `DELETE /{id}`.

При удалении пользователя, заказа, позиции аренды или единицы снаряжения зависимые объекты удаляются вместе с ним. Время создания заказа и акта осмотра ставит сервер.
